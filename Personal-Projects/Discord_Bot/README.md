/apply: Opens the registration form to assign the user's role (KomKol or Kakmerk) and generates their absurd genre-based nickname.

/certificate: Generates and uploads a custom image certificate if the user has reached the 400-hour voice chat requirement.

/ask [question]: Sends a query directly to the Gemini AI assistant and posts the response in the server.

/spin [options]: Picks a random winner from a comma-separated list (e.g., /spin pizza, burgers, tacos).

/play [url]: Connects to the user's current voice channel and plays audio from the provided YouTube link.

/stop: Stops the current audio and disconnects the bot from the voice channel.
